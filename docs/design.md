# 设计说明

MoonRoster 用于为小规模课程和资源活动安排时间与场地。项目负责把教师、班级、教室、容量和可用时段组合成可检查的安排，适合课表编制、实验室活动和小团队会议安排。

## 约束

- 同一时段内，同一教师、班级或教室不能被多个课程占用。
- 教室容量不能小于课程人数；课程只能安排在允许的时段。
- 已锁定的时间或教室必须保留。
- 搜索找到合法方案时返回方案；完整搜索后没有方案时才报告无解。达到搜索预算时返回未知，不能推断无解。

第一版使用离散时段，每项课程占用一个时段和一个教室。连续多时段、跨周规则、日历导入、多人协作和自动确定全局最优不属于第一版范围。

## 取舍与验证

确定性搜索可以让同一份输入便于复现。验证应包含可手算案例、违反每类约束的案例、锁定冲突、重复标识以及搜索预算耗尽。对于小规模问题，使用独立枚举与结果核对，避免只让求解器验证自身的输出。

项目方向由维护者选定；开发过程中使用 AI 辅助实现和检查，代码、测试和结果均应可以独立阅读和复现。
