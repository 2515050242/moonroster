# 验证记录

## 2026-11-03

项目方向由维护者选定；实现过程中使用 AI 辅助编码和验证。以下记录描述实际完成的检查，使用者可以按照命令和步骤重新验证。

- `moon check --target wasm,wasm-gc,js --deny-warn` 通过。
- `moon test --target wasm,wasm-gc,js --deny-warn` 在三个目标上各通过 14 项测试。测试包含 128 组小规模问题的独立穷举对照，以及冲突诊断和预算上限。
- `moon build cmd/web --target js --release`、`moon fmt --check` 和 `moon run cmd/main` 通过。
- 使用浏览器自动化检查了示例排程、无解、搜索上限、无效输入、表单、导入导出、键盘操作、窄屏以及文本安全显示。另以 200 个小规模输入与独立枚举对照，未发现状态不一致。
- 本地服务仅提供界面所需文件；检查了未知文件、路径穿越和非 GET/HEAD 请求的拒绝行为。

以上测试不能证明任意输入或大规模问题的性能。当前机器未验证 Native 后端。仓库中的 CI 配置将在远程服务运行后产生独立结果。

## 页面复查步骤

1. 按 README 构建并启动本地服务，打开页面，确认引擎就绪。
2. 载入示例并生成排程，核对教师、班级、时段、场地和容量。
3. 将两个课程的教师设为相同并固定在同一时段，确认返回冲突说明。
4. 导入 `examples/` 下的 JSON，生成并导出结果。
5. 修改表单，确认旧结果被清除；再使用键盘操作主要控件。
