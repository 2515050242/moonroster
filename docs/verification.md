## 资源预检与接口复查（本地）

本轮增加教师、班级与时段场地位置的二分图匹配预检，并修复显式 null 锁定字段与文档不一致的问题。新增测试包括全部 512 种三对三匹配图与独立穷举的对照、三类资源不足及恢复、放松通过但整体无解、64 门课程边界、null 与省略锁定等价及错误类型仍拒绝。三个目标各通过 27 项测试。64 门同教师课程仅能选择 63 个时段的固定用例在零搜索节点返回无解；该结果不是运行时间基准，也不表示一般大规模性能。

本轮按接口兼容修复、资源匹配预检分为两批提交，按维护者安排定时发布，实际远端验证状态以 GitHub Actions 为准。第一批独立快照的三个目标各通过 22 项测试，完整版本各通过 27 项。既有申报书的数量对应前一已发布版本，报名时需按实际发布状态同步。本地验证使用 moon 0.1.20261102、moonc v0.10.19，开发使用 AI 辅助实现与回归验证；尚未完成本人实际场景试用。

## 页面复查步骤

1. 按 README 构建并启动本地服务，打开页面，确认引擎就绪。
2. 载入示例并生成排程，核对教师、班级、时段、场地和容量。
3. 将两个课程的教师设为相同并固定在同一时段，确认返回冲突说明。
4. 导入 `examples/` 下的 JSON，生成并导出结果。
5. 修改表单，确认旧结果被清除；再使用键盘操作主要控件。
