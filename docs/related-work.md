# 相关项目

调研日期：2026-11-03。以下对照基于公开文档，不能证明其他实现不存在；提交前应再次检查。

| 项目 | 已有能力 | MoonRoster 的定位 |
| --- | --- | --- |
| [moonbit-constraint](https://github.com/mjfmjf879/moonbit-constraint) | 有限域约束、搜索、优化及排班和资源日程建模，包括固定部分变量 | 课程、教师、班级与教室的具体工作流和可交互安排；不宣称首创约束求解或锁定排班 |
| [moonopt](https://skills.mooncakes.io/docs/Freon793/moonopt%400.3.0) | 线性与整数规划、模型格式、求解和结果校验 | 离散课程场景的输入、排课结果与使用流程；不替代通用优化求解器 |

这两个项目的描述用于对照，不表示本项目复制或依赖其代码。实际依赖与许可证以模块配置为准。

复查时检索了 Mooncakes 的 `timetable`、`scheduling` 和 `moonopt`。结果也包括铁路运行图与乘客行程规划等相邻领域项目，不能据此声称不存在同类库。moonbit-constraint 的当前说明包含 MRV、节点预算、排班、资源日程与冲突诊断，和本项目核心能力存在明显交集。独立实现的取舍是针对固定领域提供小型 JSON 契约及本地操作界面，减少应用层建模步骤；代价是重复维护搜索代码，能力远少于通用库。尚无基准证据证明本实现更快或比复用现有库更合适。是否足以满足章程的独立建设理由，需要结合真实使用反馈由维护者说明、由组委会判断。
