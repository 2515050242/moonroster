# 星序 Xingxu 项目申报说明

**项目名称：**星序 Xingxu（MoonRoster）——课程与共享场地排程工具

**项目仓库：**https://github.com/2515050242/moonroster  
**主要语言：**MoonBit  
**许可证：**Apache-2.0

## 问题与目标

课程、实验室活动和社团会议常由负责人手工安排时间和场地。人员、群组和场地一多，重复占用、人数超过容量或临时调整容易造成返工。MoonRoster 面向小规模安排，提供本地数据录入、约束求解、结果查看和导出，让负责人能更快得到可复核的可行方案。

## 使用场景

1. **课程安排：**录入课程、教师、班级、教室容量和可用时段，生成不冲突的课程表；已确定的课程可以锁定时段或教室。
2. **实验室活动：**录入实验、带队教师、学生组与实验室，按人数和空闲时段安排，避免教师、学生组及实验室同时重复使用。
3. **社团活动：**录入活动负责人、参与群组、场地和可用时段，为技术分享、会议及彩排生成安排，之后可导出数据用于交流。

## 已有工作与差异

[moonbit-constraint](https://github.com/mjfmjf879/moonbit-constraint) 已提供通用约束求解、排班及固定变量等能力；[moonopt](https://skills.mooncakes.io/docs/Freon793/moonopt%400.3.0) 提供通用线性与整数规划。MoonRoster 聚焦课程、教师、班级和教室的具体使用流程：中文表单、输入导入导出、按约束生成安排、常见冲突提示以及本地浏览器使用。本项目不宣称首创约束求解或锁定排班；项目差异与来源另见 [相关项目](related-work.md)。

## 技术路线与交付

MoonBit 核心将课程的时段和教室选择建模为有限候选，使用确定性的最少候选优先搜索；每次选择检查教师、班级、场地、容量、允许时段及锁定条件。完整搜索无解与达到节点上限分别返回不同状态。核心编译为 JavaScript 供本地网页调用，网页负责录入和展示。

计划交付源码、中文网页、三个可运行示例、README、开源许可证、CI 与核心测试。验证覆盖冲突、容量、输入边界、锁定、搜索上限，以及小规模问题与独立穷举的对照。

第一版仅处理相互独立、单时段的课程安排，不承诺全局最优；连续多节、跨周规则、多人协作和大型教务系统不在本期范围。项目使用 AI 辅助编码与检查，目标选择、技术边界和最终结果由项目维护者负责。
