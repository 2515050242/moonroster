# 来源与维护记录

项目方向由维护者选择，代码、网页、测试和资料使用 AI 辅助实现、整理及验证。正式申报书由维护者另行人工撰写；本记录不表示维护者已经逐行审阅或完成实际用户试用。

当前核心使用 MoonBit 标准库 JSON 和集合能力，无第三方求解器依赖。MRV 与回溯是通用算法方法；相关项目用于能力比较，未作为本项目代码移植来源。相关工作链接见 related-work.md；工具链及标准库来自 MoonBit 官方发行，标准库源文件采用其上游许可证，不重新声称为本项目原创。

三个 JSON 示例中的名称、人员与安排均为虚构测试数据，不来自学校教务系统。网页图形为代码绘制，未引入外部图片、字体或用户数据。项目采用 Apache-2.0；将来若移植代码或加入数据，应记录其原始链接、版本、许可证、使用范围及必要的版权声明。

本轮检查发现并修正整数转换截断小数、首尾空白可能绕过人员冲突以及旧工具链格式与 CI 不一致问题；增加输入保护和可取消后台计算。复现结果见 verification.md。实际提交时间由 Git 保留，不补写虚构过程。
